# USER MANUAL - CLASSICAL CRYPTOGRAPHY STREAMLIT TOOLKIT

Welcome to the **Classical Cryptography Toolkit** built entirely with **Streamlit**.

---

## 🚀 How to Run the App

1. Open terminal in the project directory `d:\Netwok Security Project`.
2. Launch the Streamlit web application:
   ```bash
   streamlit run app.py
   ```
3. The app will automatically launch in your browser at `http://localhost:8501`.

---

## 🛠️ Included Features & Modules

- **Substitution Ciphers**:
  1. Caesar Cipher (with shift wheel dataframe)
  2. Monoalphabetic Cipher (with random key generator & mapping table)
  3. Playfair Cipher (with 5x5 matrix visualizer)
  4. Hill Cipher 2x2 (with matrix math formulas)
  5. Vigenère Cipher (with key alignment preview)
  6. One-Time Pad (with auto key generator)

- **Transposition Ciphers**:
  7. Rail Fence Cipher (with depth rail slider)
  8. Columnar Transposition Cipher (with sorted key order breakdown)

- **Utilities & Analysis**:
  9. Compare Algorithms (Live execution benchmark bar charts)
  10. Text File Encryption & Decryption (with file uploader & instant download button)
  11. Text Frequency Analysis (Histogram bar charts)
  12. Cryptography Concept Guide (Mathematical reference manual)
